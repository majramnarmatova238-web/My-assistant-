# My Assistant

Бесплатный голосовой ассистент для Android.

- Плавающая точка поверх всех экранов; нажатие открывает ассистента.
- Долгое нажатие на точку прячет её; потяните от левого края вправо (или нажмите на полоску), чтобы вернуть.
- Голосовой ввод, текстовый ввод и озвучка ответа.
- Ответы даёт FreeLLMAPI, запущенный на этом же телефоне в Termux (`http://127.0.0.1:3001/v1`).

APK собирается автоматически (GitHub Actions) и появляется в разделе Releases.
